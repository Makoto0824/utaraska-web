# `docs/`

開発以外の資料置き場（企画書・プレゼン等）は **`business/`** にまとめます。

## 運用メモ（推奨）

- **サイズ**: 画像・動画・生の PPTX はリポジトリが肥大化しやすい。可能なら **PDF で保存**するか、元データはクラウドに置いてここにはリンクのみ残す運用もありです。
- **Git LFS**: 大きなバイナリをコミットする場合は Git LFS の検討を。
- **秘匿資料**: `private` リポジトリでも、社外流出リスクの高い資料は **コミットしない**（別ストレージ）判断が安全です。
- **命名**: `YYYY-MM_テーマ-v1.pdf` のように **日付＋概要** が検索しやすいです。

詳細なフォルダ役割は `business/README.md` を参照してください。
