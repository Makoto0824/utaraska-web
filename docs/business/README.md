# Design Shelf / 会社業務資料

企画提案書・プレゼン資料など、このプロジェクトおよび事業に紐づく **ビジネス向けファイル** を置く場所です。

| ディレクトリ | 用途 |
|-------------|------|
| `proposals/` | 企画書・提案書（要件定義ドラフトなども可） |
| `decks/` | 発表用スライド。**取り込み手順・再生成コマンド**は [`decks/README.md`](./decks/README.md) 参照 |
| `archived/` | 旧版・アーカイブ（承認済みの過去バージョン） |

ファイルを追加するときは、できるだけ **`archived/` には勝ち版のみ**、`proposals/` / `decks/` は現行・アクティブ中心、と分けると整理しやすいです。
